# Week 7 — Embeddings and Qdrant

This folder contains the Week 7 standalone lab exercises for the
Srivatsasa-capstone project.

## Notebooks

- `notebooks/wk07_day1_embeddings.ipynb` — Embeddings, vector representations,
  similarity comparisons, and retrieval experiments.
- `notebooks/wk07_day2_qdrant_tour.ipynb` — Qdrant vector database setup,
  collection operations, and retrieval exercises.

## Configuration

Configure API credentials through environment variables or secure prompts.
